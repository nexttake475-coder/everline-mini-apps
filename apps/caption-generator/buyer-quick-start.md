# Caption Generator V1 — Quick Start

Caption Generator is a private, browser-based writing utility from Everline Media Systems. It runs locally and does not require an account, installation, or API key.

## Start in under one minute

1. Unzip `Everline-Caption-Generator-V1.zip`.
2. Open the unzipped folder.
3. Double-click `Caption-Generator.html`.
4. If prompted, choose Chrome, Edge, Safari, or Firefox.
5. Select a platform, enter a topic and goal, then select **Generate Caption**.

## Get stronger results

At minimum, complete the three required fields: platform, topic, and goal. For more specific output, also add your niche, audience, tone, keywords, offer, and preferred call to action.

Use commas between keywords. Example: `content systems, creator business, digital products`.

## What the app creates

- Three hook options
- One platform-aware caption draft
- One call to action
- A focused hashtag set

Use the copy buttons to move individual outputs into your publishing workflow.

## Privacy and access

The app runs entirely in your browser. Your inputs are not uploaded to Everline Media Systems. Keep the downloaded ZIP or the unzipped folder as your backup copy.

## Troubleshooting

- If the app does not open, right-click `Caption-Generator.html`, choose **Open with**, and select a modern browser.
- If a copy button is blocked, select the output manually and copy it.
- If the output is too broad, add an audience and 2–4 precise keywords.
- If the output is too short, select medium or long before generating again.
